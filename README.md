# Petteia

Juego griego de tablero. Web + Android (Capacitor).

**Jugar:** https://katiuxa.github.io/Petteia/

Misma incidencia que el resto de apps: el menú del sistema Android cubría la UI. Arreglo con insets nativos, no solo `env(safe-area-inset-bottom)`.

```bash
node server.js
npm ci && npm run apk
```
